# Java Auction System

This is an auction system I worked on for a programming assignment at Old Dominion University. The program runs in the console and allows different types of users to manage and participate in auctions.

## Features

**Customer**
- Create an account and log in
- View available auctions
- Add money to an account balance
- Place bids on auctions
- Add or remove auctions from a watchlist

**Auctioneer**
- Create new auctions
- Start and end auctions
- View auctions they have created

**Administrator**
- Create auctioneer accounts

## What I Used

- Java
- Object-oriented programming
- Classes and inheritance
- ArrayLists
- File reading and writing
- User input with Scanner
- Conditional statements and loops

## How It Works

The program has separate menus for customers, auctioneers, and administrators. Auctions can be created, viewed, and updated depending on the user's account type.

Auction information is saved to a text file so it can be loaded again when the program starts.

## Running the Project

This project was developed using Eclipse and Java 21. It requires the `Accounts.jar` library provided for the course to handle account creation and login.

The library is not included in this repository.

To run the program, add the required library to the project's build path in Eclipse and run `Main.java` in the `newPackage` package.
